## 예지보전 모델 평가의 한계 (공개 항목)

계산 대조와 별개로, 현재 데이터로는 모델 성능을 주장하기 어렵습니다.

| 항목 | 값 |
|---|---|
| 학습 데이터 | 108행, 양성 비율 87.0% |
| 평가 데이터 | 22행 중 음성 3행 |
| 모델 정확도 | 0.864 |
| 전부 '이상'으로 찍는 기준선 정확도 | 0.864 |
| 음성을 맞힌 건수 (TN) | 0 |
| ROC-AUC | 0.947 (음성 3건 기준) |

- 정확도가 기준선과 같고 음성을 하나도 맞히지 못했습니다.
- 학습/평가를 무작위로 나눠, 겹치는 5 LOT 윈도가 양쪽에 섞입니다. 시간 순서 분할이 필요합니다.

- 정상 구간이 긴 데이터를 추가로 만들거나 실제 정비 이력이 있어야 의미 있는 평가가 됩니다.
